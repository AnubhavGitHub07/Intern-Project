A full-stack web application built to practice key concepts for an internship — covering authentication, REST APIs, and React fundamentals.


## Tech Stack
| Layer    | Technology                                      |
| -------- | ----------------------------------------------- |
| Frontend | React 19, Vite 8                                |
| Backend  | Express 5, Node.js                              |
| Database | MongoDB (via Mongoose)                          |
| Auth     | JWT (jsonwebtoken), bcryptjs                    |
